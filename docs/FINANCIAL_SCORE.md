📊 ۱. تنوع سبد (Diversity) — ۲۰ امتیاز
منطق
سبدی که همه‌ی سرمایه‌اش توی یه داراییه، ریسک غیرسیستماتیک بالایی داره. تنوع‌بخشی، پایه‌ی مدیریت ریسکه.

فرمول
text
تعداد دسته‌های دارایی (که حداقل ۵٪ سبد رو تشکیل می‌دن):
│
├── ۱ دسته:   ۴ امتیاز
├── ۲ دسته:   ۸ امتیاز
├── ۳ دسته:  ۱۲ امتیاز
├── ۴ دسته:  ۱۶ امتیاز
└── ۵+ دسته: ۲۰ امتیاز
مثال
کاربر	دسته‌ها	امتیاز
علی	فقط طلا	۴
رضا	طلا + دلار + بورس	۱۲
سارا	طلا + دلار + بورس + کریپتو + ملک	۲۰
منبع داده
از جدول user_portfolio → asset_category یکتا

📊 ۲. پوشش تورم (Inflation Hedge) — ۲۰ امتیاز
منطق
هدف اصلی سرمایه‌گذاری در ایران، حفظ قدرت خرید است. اگه بازدهی کمتر از تورم باشه، سرمایه‌گذاری شکست خورده (حتی با سود اسمی).

فرمول
text
بازدهی واقعی = بازدهی سبد - تورم

├── بازدهی < تورم:             ۰ امتیاز (ارزش از دست رفته)
├── بازدهی = تورم:             ۵ امتیاز (فقط حفظ ارزش)
├── بازدهی = تورم + ۵٪:       ۱۰ امتیاز
├── بازدهی = تورم + ۱۰٪:      ۱۵ امتیاز
└── بازدهی = تورم + ۱۵٪+:     ۲۰ امتیاز
نرخ تورم مرجع
از market_snapshots → میانگین تورم ۱۲ ماه اخیر
پیش‌فرض فعلی: ۴۰٪ (اگه داده موجود نباشه)

مثال
کاربر	بازدهی سبد	تورم	بازدهی واقعی	امتیاز
علی	۳۵٪	۴۰٪	-۵٪	۰
رضا	۴۵٪	۴۰٪	+۵٪	۱۰
سارا	۵۵٪	۴۰٪	+۱۵٪	۲۰
منبع داده
از calculateStats() → totalProfitPercent - تورم مرجع

📊 ۳. نظم DCA (Discipline) — ۲۰ امتیاز
منطق
سرمایه‌گذاری منظم ماهانه، بهترین استراتژی برای کاربر ایرانی است چون:

از تلاش برای زمان‌بندی بازار جلوگیری می‌کنه

از هیجان و FOMO کم می‌کنه

میانگین قیمت خرید رو بهینه می‌کنه

فرمول
text
├── بدون DCA:                     ۰ امتیاز
├── DCA شروع شده < ۳ ماه:         ۵ امتیاز
├── DCA منظم ۳-۶ ماه:            ۱۰ امتیاز
├── DCA منظم ۶-۱۲ ماه:           ۱۵ امتیاز
└── DCA منظم ۱۲+ ماه:            ۲۰ امتیاز

از saved_calculations → اگه کاربر حداقل ۲ بار در ۳ ماه گذشته ابزار DCA رو استفاده کرده باشه، DCA فعال حساب می‌شه.

مثال
کاربر	تعداد DCA (۳ ماه اخیر)	امتیاز

سارا	۱۵	۲۰
منبع داده

📊 ۴. مدیریت ریسک (Risk Management) — ۲۰ امتیاز
منطق
معامله‌گر موفق، کسیه که قبل از سود، به ضرر فکر می‌کنه. مدیریت ریسک = بقا در بلندمدت.

فرمول (۴ زیرفاکتور × ۵ امتیاز)
زیرفاکتور	شرط	امتیاز
حد ضرر	حداقل یه محاسبه breakeven یا position	۵
صندوق اضطراری	حداقل ۳ ماه هزینه زندگی	۵
نسبت R/R	R/R ≥ ۱:۲ در محاسبات	۵
حجم معامله	max ریسک ۲٪ در هر معامله	۵
مثال
کاربر	حد ضرر	صندوق	R/R	حجم	جمع
علی	✓	✗	✗	✓	۱۰
رضا	✓	✓	✓	✗	۱۵
سارا	✓	✓	✓	✓	۲۰
منبع داده
از saved_calculations → calc_type IN ('breakeven', 'position', 'risk')

📊 ۵. پیشرفت هدف (Goal Progress) — ۲۰ امتیاز
منطق

├── پیشرفت ۵۰٪:             ۱۵ امتیاز

async function calculateFinancialScore(userId) {
  // ۱. جمع‌آوری داده
  const portfolio = await db.from('user_portfolio').select('*').eq('user_id', userId);
  const goals = await db.from('user_goals').select('*').eq('user_id', userId);
  const calcs = await db.from('saved_calculations').select('*').eq('user_id', userId);
  
  // ۲. محاسبه هر فاکتور
  const diversity = calcDiversity(portfolio);
  const inflationHedge = calcInflationHedge(portfolio);
  const dcaDiscipline = calcDCADiscipline(calcs);
  const riskManagement = calcRiskManagement(calcs);
  const goalProgress = calcGoalProgress(goals);
  
  // ۳. جمع
  const score = diversity + inflationHedge + dcaDiscipline + riskManagement + goalProgress;
  
  // ۴. بج‌ها
  const badges = calculateBadges({diversity, inflationHedge, dcaDiscipline, riskManagement, goalProgress});
  
  // ۵. ذخیره
  await db.from('financial_scores').upsert({
    user_id: userId,
    score,
    diversity_score: diversity,
    inflation_hedge_score: inflationHedge,
    dca_discipline_score: dcaDiscipline,
    risk_management_score: riskManagement,
    goal_progress_score: goalProgress,
    badges,
    calculated_at: new Date().toISOString()
  });
  
  return { score, diversity, inflationHedge, dcaDiscipline, riskManagement, goalProgress, badges };
}
